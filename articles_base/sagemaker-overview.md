## Amazon SageMaker とは

機械学習モデルの構築・トレーニング・デプロイまでを一気通貫でカバーする、フルマネージドの機械学習プラットフォームです。データサイエンティストや機械学習エンジニアが、インフラの構築・管理に時間を取られずにモデル開発に集中できるように設計されています。

[Amazon SageMaker サービス概要](https://aws.amazon.com/sagemaker/)

[Amazon SageMaker ドキュメント](https://docs.aws.amazon.com/sagemaker/latest/dg/whatis.html)

[Amazon SageMaker よくある質問](https://aws.amazon.com/sagemaker/faqs/)

[Amazon SageMaker の料金](https://aws.amazon.com/sagemaker/pricing/)

自前で GPU インスタンスを構築し、フレームワークのセットアップからモデルのデプロイ用インフラまで管理する代わりに、SageMaker がこれらのプロセスをマネージドサービスとして提供します。

## 機械学習の基本的な開発フロー

機械学習プロジェクトは、一般的に「データの準備」「モデルの構築・トレーニング」「モデルの評価」「デプロイ（推論エンドポイントの公開）」「モニタリング・再学習」というサイクルを繰り返します。SageMaker は、このサイクル全体を単一のプラットフォーム上でカバーすることを目指したサービス群として設計されています。

## 主な機能

### SageMaker Studio

機械学習開発のための統合開発環境（IDE）です。Web ブラウザ上で、ノートブックの作成、実験の追跡、モデルのデバッグ、パイプラインの管理などを 1 つの画面から行えます。

### ノートブックインスタンス

Jupyter Notebook 環境をマネージドに提供する機能で、データの探索的分析やモデルのプロトタイピングに利用します。

### トレーニングジョブ

指定したアルゴリズムとデータを使ってモデルの学習を行う機能です。学習に必要なインスタンスは、ジョブの実行中だけ起動し、完了後は自動的に停止するため、学習していない時間帯の課金を避けられます。分散トレーニングやスポットインスタンスを使ったコスト最適化にも対応しています。

### 推論エンドポイント

学習済みモデルを HTTPS エンドポイントとして公開し、リアルタイムで推論結果を返せるようにする機能です。リアルタイム推論のほか、大量データをまとめて処理するバッチ変換、呼び出し頻度が低いモデル向けのサーバーレス推論、複数モデルを 1 つのエンドポイントに集約するマルチモデルエンドポイントなど、用途に応じた推論方式を選択できます。

### SageMaker Canvas

コードを書かずに、ノーコード・ビジュアル操作で機械学習モデルを構築・利用できるツールです。機械学習の専門知識が少ないビジネスアナリストなどを主な対象としています。

### SageMaker Autopilot

データを指定するだけで、前処理・アルゴリズム選定・ハイパーパラメータチューニングまでを自動化する AutoML 機能です。生成された候補モデルの中から、精度の高いものを選んで利用できます。

### SageMaker Feature Store

複数のモデル・チームで再利用できる特徴量（Feature）を一元管理するリポジトリです。学習時と推論時で特徴量の定義がずれる「トレーニング・サービング スキュー」を防ぐのに役立ちます。

### SageMaker Pipelines

データ準備からモデルのデプロイまでの一連の処理を、CI/CD のようにパイプライン化し、再現性を持って自動実行するための機能です。MLOps（機械学習における継続的な開発・運用）を実践する際の基盤になります。

## SageMaker Unified Studio と名称変更

近年、SageMaker のブランド構成が整理され、モデル開発のコア機能は「SageMaker AI」として再定義されました。加えて、データエンジニアリング・SQL 分析・BI・機械学習・生成 AI アプリ開発までを 1 つの Web 画面から扱える「SageMaker Unified Studio」が提供されており、機械学習に閉じないデータ活用基盤としての位置付けが強まっています。名称や機能構成は変更される可能性があるため、最新の体系は公式ドキュメントで確認してください。

## Amazon Bedrock との違い

いずれも AI/ML 関連のマネージドサービスですが、主眼が異なります。

- Amazon Bedrock：Anthropic の Claude をはじめとする、様々なベンダーの基盤モデル（生成 AI モデル）を API 経由で呼び出す・カスタマイズすることに特化したサービス
- Amazon SageMaker：自前のデータで一から機械学習モデルを構築・学習・デプロイする、より汎用的な機械学習基盤（需要予測、異常検知、レコメンデーションなど、生成 AI に限らない機械学習全般をカバー）

生成 AI アプリケーションを素早く作りたい場合は Bedrock、独自データで独自モデルを構築したい、あるいは伝統的な機械学習（回帰・分類など）に取り組みたい場合は SageMaker、という使い分けが基本的な考え方です。両者を組み合わせて使うことも増えています。

## ユースケース

- 需要予測、在庫最適化などの回帰・時系列予測モデルの構築
- 不正検知、異常検知モデルの構築・運用
- レコメンデーションエンジンの構築
- 画像認識・自然言語処理などのカスタムモデルの学習
- MLOps パイプラインによるモデルの継続的な再学習・再デプロイ

## 料金

主要な料金は、ノートブックインスタンスやトレーニングジョブ、推論エンドポイントとして起動するコンピューティングインスタンスの稼働時間に対する従量課金です。トレーニングジョブはジョブ実行中のみ、リアルタイム推論エンドポイントは起動している間、常時課金される点に注意が必要です。サーバーレス推論やバッチ変換など、利用形態によって課金の考え方が異なります。初回利用から一定期間の無料利用枠も用意されています。詳細は [Amazon SageMaker の料金ページ](https://aws.amazon.com/sagemaker/pricing/) を確認してください。

## メリット

- 機械学習開発に必要な機能（データ準備、学習、デプロイ、監視）を単一プラットフォームでカバーできる
- インスタンスの管理を意識せず、必要なときだけ計算資源を使う従量課金モデル
- Canvas や Autopilot など、機械学習の専門知識が少ないユーザー向けの選択肢もある
- Feature Store や Pipelines により、チームでの再利用性・再現性を高められる

## デメリット・注意点

- 機能が非常に多岐にわたるため、全体像を把握するまでの学習コストが高い
- リアルタイム推論エンドポイントは起動している間ずっと課金されるため、利用予測を誤るとコストが膨らみやすい
- 生成 AI を手早く使いたいだけの場合は、SageMaker よりも Bedrock の方が適していることが多い
- ブランド・機能構成が変更されることがあり、ドキュメントや学習教材が古い名称のままになっている場合がある

## 📖 まとめ

Amazon SageMaker は、データの準備からモデルの学習、デプロイ、運用までを一気通貫でカバーする機械学習プラットフォームです。ノートブックによるコーディング中心の開発から、Canvas・Autopilot によるノーコード／自動化まで、幅広いスキルレベルに対応した機能が用意されています。生成 AI 基盤モデルの活用に特化した Amazon Bedrock とは役割が異なるため、取り組みたい課題（独自データでの機械学習か、生成 AI の活用か）に応じて使い分けることが重要です。
